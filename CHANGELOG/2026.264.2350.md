# 2026.264.2350 — fix(ci): drop the dead cue:gen step left by the params/schema removal

## Summary

PR #16 removed `candy/plugin-review/schema/review.cue` and the generated `params/cue_types_gen.go` (the deleted `verb:pr` typed input), but its stale-reference sweep was scoped to `candy/plugin-review/` — so it missed the **repo-root CI workflow**, which still regenerated params from the deleted schema. The `test` job then failed on `main`:

```
cat candy/plugin-review/schema/review.cue
cat: candy/plugin-review/schema/review.cue: No such file or directory
##[error]Process completed with exit code 1.
```

This repo now has no CUE schema and no generated params, so the cue:gen reproducibility step (and its pinned `cue` install) is removed. The change-class gate for this plugin is `gofmt`/`vet`/`test`, which remains. The stale `incl. the full-loop e2e` label is dropped (there is no tool loop).
