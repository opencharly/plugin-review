# 2026.264.1425 — refactor(review): prime the full PR context + bounded tool loop; embed the prompt; env-driven config

## Summary

Rewrite the review engine to a **pure function**: assemble the complete PR context into **ONE message**, make **ONE model call**, extract the verdict, emit the effects.

```
FromEnv() → assemble() → render() → ONE message → ONE llmkit call → verdict → Emit()
```

A review is a function of `(rulebook, complete PR, model)` — all input is read **once** and sent **once**, so there is nothing for the model to fetch and no tool loop.

### Measured root cause (why the loop was the problem)

The previous engine assembled the context turn by turn through a tool-calling loop, and message reasoning is **not re-sent between turns** — so the synthesis turn re-derived everything from partial tool results. Measured on a 25-file PR: **371 KB** of reasoning over three runaway synthesis turns (**8m25s**, no verdict at cap). Delivering the whole context in ONE message produced a verdict from **ONE call** (measured live: 1m24s on action-review#7; 2m55s on spec#140).

### What was removed

- **The tool-calling loop** (turn budget, `AI_REVIEW_MAX_TURNS`, tool dispatch, `sdkTools`, the `chatTurn` seam) and `tools.go`'s 7 review tools. The prompt no longer mentions any tool, so prompt and runtime cannot drift.
- **`verb:pr`** (`pr_meta`/`pr_commits`/`pr_thread`/`pr_files`) — it **duplicated `plugin-gh`'s canonical `verb:gh`** (the same ghkit reads) and had **no consumer**. Deleted with its schema, generated `params/`, and the verb-only helpers. plugin-review declares no typed input def, so per `sdk.BuildCapabilities`' documented path an input-less plugin passes a nil schema (no schema dir).
- **Retry/ladder experiments** (reverted; `classify()` fails once, terminally).
- `openai-go` is no longer imported by the PRODUCTION code (only `llmkit` uses it internally). It remains in the DIRECT `require` block because `review_test.go`'s chat seam names the SDK's `openai.ChatCompletionMessageParamUnion` / `openai.ChatCompletionToolUnionParam` types (a test-only import).
